# self-deploy

**self-deploy** is a lightweight helper tool designed to make it easy for anyone to automatically run and manage servers on their own infrastructure. It detects deployments to GitHub and takes care of updating your server code so you can utilize spare hardware or cloud VMs as personal deployment agents.

---

## Features

- **Automatic Deployments** — Detects new GitHub pushes and updates your code.
- **Simple CLI** — Easy to initialize and control via a user-friendly command-line interface.
- **Flexible** — Ideal for hobbyists, small projects, and home lab enthusiasts.
